Telemetry lab API

Run bounded virtual-charger scenarios through the same service used by the CLI and dashboard. The API never connects to charger hardware.

GET/health

Process liveness and synthetic-only operating mode.

GET/api/v1/presets

Fault profiles for network, message, sensor, and mixed reliability drills.

POST/api/v1/scenarios

Generate telemetry, inject failures, validate detection, and verify retry/reconnect recovery.
